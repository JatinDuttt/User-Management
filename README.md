# User Management Studio

A React-based user management app built with a Vite-style project structure. The UI is split into reusable components, the stateful logic lives in a custom hook, and browser persistence is handled through small storage utilities.

## Stack

- React
- Vite
- Plain CSS
- Local storage for persistence

## Project Structure

```text
src/
  components/
  data/
  hooks/
  lib/
  styles/
  utils/
```

## Scripts

```bash
npm install
npm run dev
```

## Features

- Add, edit, delete, and browse users
- Live search, role filters, and sorting
- Reusable React components
- Modular helpers for validation, dates, transforms, and storage
- Demo data loader for quick testing
